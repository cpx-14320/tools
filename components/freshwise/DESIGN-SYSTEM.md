# FreshWise V2：蔬果夥伴遊戲介面

參考：`UIUX示意設計稿/FreshWise_V2_蔬果夥伴`。僅影響 FreshWise，其他小工具使用自己的設計系統。

## 文字與插畫分工

- **HTML**：標題、建議句、食材名稱、價格與估算區間、單位、資料日期、來源、表單、任務進度、寵物名稱、等級、獎勵與按鈕。可選取、可換行，可配合實際資料更新。
- **SVG**：原有走勢圖與範圍指示，保留真實數值、觸控與準星。
- **PNG**：無文字的花園場景、六位夥伴、圖鑑、小圖示及依實際品項生成的食材圖集。
- **CSS**：棚布、紙張外框、葉片按鈕、手帳分隔線、導覽木架、字體與間距。沒有把整張設計稿當背景。

## 視覺規範

主視覺是連續花園與角色舞台；行情是一張共享價目紙；菜籃和設定是一份手帳，避免每一列再堆一個等尺寸卡片。
`game.css` 集中新的排版規範，`theme.ts` 提供舊元件相容的色票與文字階層。

## 素材與解析度

素材位於 `public/freshwise/{scene,companions,ui,items}`。完整檔名、格位、品項代碼、原生尺寸與倍率見 `public/freshwise/assets-manifest.json`；內建 image_gen 的完整提示詞見 `asset-prompts.json`。

- 六位夥伴各有 1254×1254 原生透明 PNG，最大顯示 200px，約 6.27 倍。
- 功能圖集 1536×1024、6×4 格，每格 256px，最大顯示 40px，6.4 倍。
- 95 個有來源的品項分四張相同規格圖集，依固定品項代碼對應。最後一張的最後一格留白。
- 圖鑑每格 512px，顯示 76px，約 6.74 倍；紙紋 1254px，重複顯示 128px，約 9.8 倍。
- 花園場景原生 1448×1086，430px 寬舞台約 3.37 倍，**此項未達 6 倍**。記錄真實解析度，沒有以插值放大冒充額外細節。之後如取得更高原生場景，直接替換同名素材並更新索引。

圖集由 CSS background-position 在網頁上取格，沒有破壞性裁切原始素材。固定代碼表在 `lib/freshwise/art-assets.ts`，新增／排序目錄不會使舊圖位移。新增品項未有圖時使用對應分類插畫，待補圖後更新代碼表。

## 資料誠實性

以現行 `lib/freshwise` 的價格簿和來源規則為準，不使用設計稿示例數字。
保留估算範圍、資料日期、歷史不足、休市／延遲、批發非零售、個別來源、完整行情表及標章比較。
估算品項不顯示衍生的「漲跌／划算度」當成實測結論。
菜籃未有行情的項目不計入總額；未填份量也不假設份量。

## 夥伴與任務

新頁面 `/tools/freshwise/companions`。夥伴、每隻成長、露珠、印章、當日任務與介面偏好保存在這台瀏覽器的 `freshwise.companions.v1`，尚未雲端同步。
初次有高麗菜糰糰與 6 露珠；澆水 3 露珠換 3 成長；每天首次陪玩增加 2 成長。40 成長升一級。
探索印章依序解鎖蘿蔔、草莓、南瓜、茄子與玉米角色。南瓜是花園角色，沒有對應查價入口，不假造行情。

任務只在有意義的操作後記錄：看三個不同的有行情詳情、在有走勢時切換期間、補齊一個原本未填且有行情的菜籃份量。
每個任務每日僅領一次，臺灣日期跨日重置任務而保留養成。領獎後顯示來信，可關閉，不擋查價。
沒有付費、購物或連續登入要求；離線不扣等級。支援收起夥伴、簡潔模式、減少動態與系統 prefers-reduced-motion。

## 驗證

既有回歸：`npm run check:freshwise`。
新增養成與素材檢查：`node node_modules/tsx/dist/cli.mjs scripts/freshwise-companion-check.mts`。
型別：`npx tsc --noEmit`；建置：`npm run build -- --webpack`。
隔離快照的測試行情與預覽路由不會複製到正式專案，正式頁面維持原有登入、權限與真實價格來源。
