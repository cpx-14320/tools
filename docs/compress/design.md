# 圖片壓縮 — 設計系統

> 2026-11-28 建立。**這個工具沒有自己的色票。**

`app/tools/compress` 只有一頁，走的是入口／登入／後台那一套：
`app/globals.css` 的 `:root` 色票 ＋ `components/ui.tsx` 的共用元件。

所以要改這個工具的樣式，讀 **[../hub/design.md](../hub/design.md)**。

為什麼不給它一套自己的：三個工具各有 `theme.ts` 是因為它們各自有一整套視覺語言
（搭乘車紫、記帳本紫、菜鳥買菜記綠，各幾十個 token、各自的插畫風格）。圖片壓縮是一頁
選檔、壓縮、下載，開第四套設計系統只會多一份要同步維護的色票。

這一頁在視覺上唯一要守的事：**它看起來要像入口頁的延伸**，不要長得像另一個 App——
使用者是從入口頁點進來的，中間沒有經過任何「進入某個工具」的轉場。
