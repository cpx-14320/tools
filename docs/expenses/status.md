### 2. 股票／黃金的實際市值

**現況**：帳戶餘額是 `期初 + 收入 − 支出 ± 轉帳`，所以「股票」帳戶顯示的是**投進去多少錢**，
不是**現在值多少**。要算市值，缺的不只是價格，是**持倉**（哪一檔、幾股、成本）。

資料來源都免費免金鑰：上市走 TWSE OpenAPI 的 `exchangeReport/STOCK_DAY_ALL`（一支 API 拿到
當日全部收盤價）、上櫃走 TPEx OpenAPI、黃金走台銀黃金存摺牌價。盤後資料一天只變一次，所以做
**MongoDB 快取 ＋ 當日第一次請求才更新**（`expenses.marketPrices`，以 `(symbol, date)` 當鍵），
比照搭乘車 `transit.tdxCache` 的做法，不用排程器。

三種資料模型，**建議第 2 種、分兩步走**：

1. 手動市值（最輕，不接 API）：帳戶多一個「目前市值」欄位，自己更新。
2. **持倉 ＋ 自動報價**：帳戶底下可以新增持倉（代號、股數、平均成本），市值 ＝ Σ(股數 × 收盤價)。
   先做「持倉 ＋ 手動報價」把資料模型與介面定下來，再接 API 自動化（那時只是把一個欄位從手填
   換成每日更新，介面不用再改）。
3. 完整投資模組（配息、拆股、成本法、報酬率）——那是另一個工具的規模，不建議塞進記帳本。

**還沒決定**：(a) 走第 2 種嗎 (b) 只做台股＋黃金，還是也要美股（美股免費來源較不穩）
(c) 黃金記「公克」還是「台錢」。
