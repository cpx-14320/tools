## 未處理

| 項目 | 說明 |
| --- | --- |
| 骨架與版面要靠人工保持一致 | 這是五個工具裡唯一還用骨架的。改版面忘了改 `skeleton.tsx` 時沒有任何東西會擋下來——載入完成的瞬間會整頁跳動。`check:transit` 測不到這件事（它只測純函式與靜態資料） |
| 轉乘路徑演算法沒有測試 | `metro-routing.ts` 的最短路徑（`computeMetroTrip`）要打 TDX 拿站間行車時間才算得出來，所以不在 `check:transit` 的範圍。要測的話得先把「圖的建構」與「打 API 取資料」拆開，讓前者吃假資料 |
| 公車路線搜尋、附近站牌 | 同上，`bus-routing.ts` 會用到的函式幾乎都要打 TDX。目前只驗了縣市代碼對照那一層 |
| 只有手機版版面 | 跟另外兩個工具一致，刻意的；但沒有正式確認過要不要做電腦版 |
